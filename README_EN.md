# kiran-desktop

## Overview

kiran-desktop provides the `libkiran-desktop` library and orchestrates the installation of all Kiran ecosystem components along with their mandatory open-source dependencies.

The `libkiran-desktop` library provides shared APIs utilized across multiple applications.

## Software Architecture

Currently, it only provides a secondary wrapper for wireless network functionalities built on top of `kf5-networkmanager-qt` (Qt wrapper for NetworkManager API).

## Instruction

For implementation details, refer to the directories under `examples/`.
